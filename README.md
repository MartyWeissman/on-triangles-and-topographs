# On Triangles and Topographs

**Martin H. Weissman** · University of California, Santa Cruz  
[ORCID: 0000-0003-2078-1185](https://orcid.org/0000-0003-2078-1185)

A Lean 4 formalization of a classification of hyperbolic cosine triples, with
commented proofs and lessons for readers learning formalization. The current
release covers the cosine-triple classification; it does not yet formalize a
general theory of topographs.

**Status:** the classification is proved in both directions for arbitrary
triples. The library and lessons compile with the pinned dependencies, and an
axiom audit includes the final theorem. This is an initial release candidate,
not a claim of independent peer review. See [verification](verification/README.md).

## The mathematical statement

Let integers satisfy \(2\le e\le f\le g\), and put

\[
a=2\cos(\pi/e),\quad b=2\cos(\pi/f),\quad c=2\cos(\pi/g),
\qquad F=\mathbb Q(a,b,c),\qquad D=a^2+b^2+c^2+abc-4.
\]

We classify triples satisfying \(1/e+1/f+1/g<1\) and
\(\sigma(D)<0\) for every rational-field embedding
\(\sigma:F\hookrightarrow\mathbb R\) other than the distinguished inclusion.
The field is the **full cosine field** generated by all three cosines. The
condition quantifies over embeddings of this field, including any nonidentity
embedding that fixes \(D\).

These 25 triples form a subset of Takeuchi’s classification of arithmetic
triangle groups in Theorem 3 (1977). See the [full reference](docs/References.md).
The Lean theorem concerns the full-cosine-field condition stated here; it does
not formalize Takeuchi’s general classification.

There are exactly **25** triples. With \(S=\{4,5,6,7,8,9,12,15\}\):

| Family | Triples |
|---|---|
| Right | (2,3,7), (2,3,9), (2,3,11), (2,5,5), (2,7,7) |
| Initial pair 3 | (3,3,n), n ∈ S |
| Diagonal | (n,n,n), n ∈ S |
| Other isosceles | (3,5,5), (4,5,5), (5,5,10), (5,5,15) |

The main theorem in [Classification.lean](ArithmeticTriangles/Classification.lean) is:

```lean
theorem arithmeticHyperbolic_iff_mem (t : Triangle) :
  t.ArithmeticHyperbolic ↔ t ∈ expectedArithmeticTriples
```

Here `ArithmeticHyperbolic` includes ordering, the lower bound 2, hyperbolicity,
and the embedding condition. The theorem has no assumed upper bound on the
denominators. Every non-right triple in the classification is isosceles.

## Reproducing the proof checks

Install Git, Python 3, and Lean's [elan toolchain manager](https://github.com/leanprover/elan).
From this directory, in a Bash-compatible environment:

```sh
./lakew exe cache get
./scripts/verify.sh
```

The committed `lean-toolchain` selects Lean **4.35.0**. The committed
`lake-manifest.json` fixes mathlib and its dependencies to exact revisions.
The first command obtains mathlib's compiled cache; the second builds this
library, checks the dependency revisions, compiles the lessons, and audits
238 named declarations. Initial setup needs internet access and several
GB of disk space for dependencies and build products.

See [Reproducibility.md](docs/Reproducibility.md) for the trust boundary,
individual commands, and recorded local checks. Do not run `lake update`
as part of reproducing this version: it can change the dependency lock.
